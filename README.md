# 250 игр — личный чек-лист

Одностраничный трекер для списка 250 лучших игр по версии Metacritic. Отмечайте пройденные игры, ставьте личную оценку и следите за прогрессом. Все данные хранятся только в вашем браузере.

**Открыть сайт:** https://filippovyasha0-debug.github.io/top250-games/

## Возможности

- Чек-лист из 250 игр с обложками, Metascore, годом, платформами и жанрами.
- Отметка «Пройдено», дата прохождения и личная оценка от 1 до 10.
- Поиск, фильтры по жанру, платформе, десятилетию и статусу.
- Сортировка по месту в списке, Metascore, году, названию, вашей оценке и дате прохождения.
- Статистика: количество пройденных игр, средняя оценка, прогресс за год, оставшиеся игры.
- Случайная игра из непройденных — «Что пройти дальше?».
- Экспорт и импорт прогресса в JSON, полный сброс с подтверждением.
- Тёмная тема, адаптивная вёрстка и управление с клавиатуры.
- Работает офлайн: все данные и обложки лежат рядом с сайтом.

## Как пользоваться

1. Откройте `index.html` двойным щелчком — сайт работает без сервера и интернета.
2. Нажмите на карточку, чтобы открыть подробности и поставить дату и оценку.
3. Используйте чекбокс на карточке, чтобы быстро отметить игру пройденной.
4. Для резервной копии откройте «Данные» → «Экспортировать JSON».

Прогресс сохраняется в `localStorage` браузера. Он привязан к конкретному браузеру и адресу страницы. Очистка данных браузера или переход на другое устройство не перенесут прогресс автоматически — для этого используйте экспорт и импорт.

Горячая клавиша `/` переводит курсор в поле поиска.

## Локальный сервер (необязательно)

Для проверки через HTTP:

```bash
node scripts/preview-server.mjs
```

Сайт откроется на `http://127.0.0.1:4173/`. Сборка не требуется.

## Структура проекта

```text
index.html              разметка страницы
styles.css              оформление
app.js                  логика, фильтры, прогресс, импорт и экспорт
data/games.js           встроенный список 250 игр (window.GAMES)
assets/covers/          обложки в WebP
scripts/fetch-data.mjs  загрузка данных и обложек с Metacritic
scripts/preview-server.mjs  простой локальный сервер
```

## Обновление данных

Нужен Node.js 18+ и доступ в интернет.

```bash
npm install
node scripts/fetch-data.mjs
```

Скрипт загружает список и обложки, сжимает изображения через `sharp` и перезаписывает `data/games.js` и `assets/covers/`. Исходные ответы кэшируются в `.cache/` — эту папку не нужно публиковать или коммитить.

Список строится по Metascore: берутся первые 250 уникальных игр, место в интерфейсе присваивается последовательно. Методика и порядок принадлежат Metacritic; список не является официальным.

## Публикация

### GitHub Pages

В корне проекта:

```bash
git init
git add .
git commit -m "Add top 250 games checklist"
gh repo create top250-games --public --source=. --remote=origin --push
```

Затем в настройках репозитория: **Settings → Pages → Source → Deploy from a branch → main / (root)**. Сайт будет доступен по адресу `https://<username>.github.io/top250-games/`.

Без GitHub CLI создайте пустой репозиторий на github.com, выполните `git remote add origin <url>` и `git push -u origin main`.

### Netlify

Перетащите папку проекта в [Netlify Drop](https://app.netlify.com/drop) или подключите Git-репозиторий. Команда сборки не нужна, каталог публикации — корень проекта. Перед публикацией можно исключить `node_modules/`, `.cache/` и `scripts/` — для работы сайта они не нужны.

## Важно

- Проект неофициальный и не связан с Metacritic. Названия игр, оценки и обложки принадлежат их правообладателям и используются для идентификации игр.
- Данные и обложки получены с Metacritic и могут отличаться от текущей версии сайта.
- Личные отметки, даты и оценки никуда не отправляются.
